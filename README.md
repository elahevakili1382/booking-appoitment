# Lumina Clinic (Vue)

Landing site for **Lumina Clinic** — bilingual (FA/EN), built with Vue 3 from the Google Stitch *Aura Lumina* design.

## Run

```bash
npm install
npm run dev
```

## Stack

- Vue 3 + Vite + TypeScript
- Tailwind CSS v4
- motion-v (Motion for Vue)
- Vazirmatn + Playfair Display / Plus Jakarta Sans
